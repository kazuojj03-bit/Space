# SpacePhone 3.2 RC1 — source for review

**Status: compiled preview. Final native tests after the latest trade fix were not completed. No scan clearance is claimed.**

Complete phone-only source: 34 C# files and one project. The BepInEx plugin adds Lost Call (Yu Deng and an original route recorder), recurring Night Orders, partner follow-ups, guidance, and input/reservation fixes. Original dialling and native counter transactions remain available. Upper District and the independent game are outside this version.

plugin/ holds exact production sources; SOURCE-MANIFEST.json lists SHA256 and the corresponding DLL identity. Assets/ holds all 21 required procedural phone PNGs. New characters, recorder sprite/definition, phone mesh and night signal are generated by the C# sources. BUILD.md explains local-reference compilation; ASSET-SOURCES.txt and art_sources/ document raster origin. Historical drawing scripts are preserved for review; check their output paths before executing them. LICENSE.txt retains author rights and third-party terms.

No game assemblies, interop binaries, fonts, loader/runtime, browser profiles, personal saves/music, or private QA logs are included. This repository source does not include a playable compiled release; download availability and exact testing limits are described with the corresponding Nexus file. The build instructions do not claim byte-identical rebuilds.

The branch codex/spacephone-3-2 is version-specific. Main and immutable 3.1 commit 6f83b7b55a57e9fd9b69b91b6997100900b127a0 are preserved. They are not source correspondence for the 3.2 DLL.

AI was used extensively for code, dialogue, UI and asset-generator design. Use AI-Generated Content on Nexus and AI Media for AI-created promotion/page copy. Gameplay stocks are local simulation. This version does not distribute the BrowserHost executable: fresh installs lack in-game Douyin/TikTok browsing; an existing 3.1 host can be retained, but updated host/site/login compatibility is outside this release verification. No automatic update network service is included.
